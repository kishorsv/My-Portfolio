---

## ?? Architecture & Highlights

- **Hero Experience**: Asymmetric editorial layout with HLS video ambient background (`hls.js`), rotating dynamic role pills, and magnetic button physics.
- **Visual Design Philosophy**: Dark monochromatic aesthetic (`#080808` base), subtle film grain, technical grid, custom magnetic cursor with contextual states (`VIEW`, `?`), and fluid typography clamps.
- **Interactive Tech Stack**: Domain-filtered technology cloud (`ALL`, `AI`, `GENAI`, `FRONTEND`, `BACKEND`, `LANGUAGES`, `TOOLS`) with spotlight dimming.
- **Bento Selected Works**: Curated showcase of 7 best production builds featuring 3D card perspective tilt, Problem ? Solution ? Result breakdown, and deep-dive case study modal.
- **Core Capability Matrix**: Ambient glowing shader cards covering Generative AI & Agents, High-Performance Web, Scalable Backend & APIs, and Production Machine Learning.
- **Engineering Timeline**: Milestone timeline powered by GSAP ScrollTrigger drawing lines.
- **Verified Credentials & Achievements**: NxtWave, Google GenAI, Microsoft, Kaggle, DeepLearning.AI verified certificates and state-level sports / hackathon milestones.
- **SVG Contribution Heatmap**: High-reliability client-rendered SVG GitHub contribution graph and live repository metrics.
- **Inspectable Resume**: Interactive modal for curriculum vitae preview + PDF download trigger.

## ?? Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/kishorsv/New.git
cd New
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open `http://localhost:5173` in your browser.

### 4. Build for production
```bash
npm run build
```
Generates optimized chunks in `/dist` ready for Vercel, Netlify, or GitHub Pages.
